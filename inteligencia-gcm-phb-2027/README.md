# Inteligência GCM PHB 2027

Guia didático de disciplinas, legislação e conhecimentos locais para a preparação pré-edital da Guarda Civil Municipal de Parnaíba (PI).
É independente e não oficial.

- `Inteligencia_GCM_PHB_2027.pdf`: o guia final (A4, 215 páginas).
  - 8 disciplinas, 91 tópicos e 242 exercícios originais com gabarito comentado.
  - Resumos, checklist e plano de revisão preenchíveis, além de recursos complementares.

## Código-fonte (`src/`)

| Arquivo | Conteúdo |
|---|---|
| `d_port1.py`, `d_port2.py` | Língua Portuguesa |
| `d_cf.py` | Constituição Federal |
| `d_lei.py` | Lei nº 13.022/2014 |
| `d_dh_adm.py` | Direitos Humanos e Administração Pública |
| `d_info.py` | Informática |
| `d_mat.py` | Matemática e Raciocínio Lógico |
| `d_local.py` | Parnaíba |
| `render.py`, `motor.py`, `qbase.py` | Layout, tópicos, exercícios e capa |

Para gerar de novo: `python3 src/gerar_pdf.py`.
