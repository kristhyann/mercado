# Organização dos arquivos

```
.claude/skills/professor-gcm-parnaiba/   ← a Skill (instruções, metodologia, kit de PDF)
GCM-PARNAIBA/                            ← os materiais de estudo do usuário
├── README.md                            ← catálogo de tudo o que já foi produzido
├── apostilas/                           ← PDFs finais: NN_Tema_GCM_Parnaiba.pdf
│   └── fonte/NN-tema/                   ← código-fonte de cada apostila (kit + gerar.py + config.json)
├── questoes/                            ← simulados e listas avulsas (PDF ou .md)
├── revisoes/                            ← resumos, flashcards, caderno de erros, plano D+1/D+7/D+30
└── fontes/
    ├── edital/                          ← edital oficial, avisos do DOM, conteúdo programático transcrito
    ├── legislacao-municipal/            ← leis de Parnaíba recebidas do usuário
    └── notas-de-verificacao.md          ← registro de artigos e fatos conferidos (fonte e data)
```

## Nomes de arquivo
- Apostilas: `01_Codigo_Penal_GCM_Parnaiba.pdf`, `02_Conhecimentos_Profissionais_GCM_Parnaiba.pdf`… (numeração na ordem de criação).
- Novas edições: `_v2`, `_v3`. Nunca apague a anterior sem autorização.
- Fonte de cada apostila: `GCM-PARNAIBA/apostilas/fonte/01-codigo-penal/`.

## Ordem sugerida das apostilas (pelo peso provisório)
1. Código Penal · 2. Conhecimentos Profissionais (Lei 13.022/2014 + legislação de Parnaíba) · 3. Língua Portuguesa · 4. Conhecimentos Regionais de Parnaíba · 5. Informática · 6. Raciocínio Lógico · 7. Simulado geral (50 questões).
