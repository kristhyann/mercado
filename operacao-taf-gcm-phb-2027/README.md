# Operação TAF GCM PHB 2027

Guia de preparação física progressiva para iniciantes que querem se preparar para um possível TAF da Guarda Civil Municipal de Parnaíba (PI).
É preparação física geral. Não contém critérios oficiais e não substitui avaliação profissional.

- `Operacao_TAF_GCM_PHB_2027.pdf`: o guia final (A4, 54 páginas, sumário clicável e páginas preenchíveis).
- `src/gerar_pdf.py`: gera o PDF de novo. Os outros arquivos de `src/` são:
  - `conteudo.py`: capítulos e planos
  - `visuais.py`: capa, ilustrações esquemáticas e diagramas
  - `motor.py`: layout

Para gerar de novo: `python3 src/gerar_pdf.py` (requer reportlab).
